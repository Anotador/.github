# Anotador

Label any dataset one item at a time, with the keyboard. Moderation, sentiment, relevance, quality control, review of model output and more.

Anotador is a single HTML file that runs in your browser. It opens XLSX, CSV, TSV, JSON and JSONL files and saves your labels as a CSV. There is nothing to install and no server: it works offline, nothing is uploaded and your data stays in your browser. It comes with 24 label presets, from moderation, jailbreak and prompt injection to sentiment to answer checking and ratings, all editable.

*Anotador* is Portuguese for "annotator".
